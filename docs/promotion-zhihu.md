## 文章标题

想学 AI Agent 却不知道从哪本书开始？我把 GitHub 上最热的 26 个宝藏仓库全扒出来了

## 正文

想学 AI Agent，打开 GitHub 搜一下 "agent"，能出来几十万条结果。

书单满天飞，但大部分是人工整理的，star 数早就过时了；还有些干脆就是链接堆砌，没有难度分级，初学者根本不知道该从哪本开始。

所以我做了一份「活的」书单：26 个仓库，按主题分成六大类，每个都标注了难度（🟢 入门 / 🟡 进阶 / 🔴 深度），star 数每天自动更新，榜单永远是最新的。

直接说结论，按难度推荐：

**🟢 入门（零基础友好）**

1. 《深入理解 AI Agent》（41k⭐）—— 目前最火的中文 Agent 书，李博杰著。正文、PDF、配套代码全部开源。学 Agent 的第一本基本就是它。
2. Hugging Face Agents Course（31k⭐）—— HF 官方课程，入门首选，教材免费。
3. Hermes Agent 橙皮书（4.9k⭐）—— Nous Research 开源框架实战指南，跟着敲一遍就能上手。

**🟡 进阶（有基础，想深入）**

4. 《御舆：解码 Agent Harness》（4.1k⭐）—— 42 万字拆解 Agent 的 Harness 骨架，Claude Code 用户必读。
5. Harness Engineering 两卷本（2.9k⭐）—— Claude Code 和 Codex 背后的设计哲学，读懂了就知道主流 Agent 工具是怎么设计的。
6. Generative AI with LangChain（1.4k⭐）—— O'Reilly 出版，LangChain / LangGraph 生产级实战。

**🔴 深度（做研究 / 准备面试）**

7. LLM-Agent-Paper-List（8.2k⭐）—— SCIS 封面论文配套清单，读论文从这份开始。
8. Awesome-Agent-Papers（2.8k⭐）—— LLM Agent 综述：方法论、应用与挑战。

完整书单（26 个仓库、Top 10 总榜、推荐阅读路线）：

📚 https://github.com/gotonote/awesome-agent-boom
🌐 在线书单（网页版，手机也能看）：https://gotonote.github.io/awesome-agent-boom/

书单每周更新，你最近在看哪本？评论区聊聊，有好书也可以推荐给我，一起维护。
